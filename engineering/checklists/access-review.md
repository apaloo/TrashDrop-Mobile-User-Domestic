Quarterly access review (Access control policy, rule 6).

For every system in the [access register](../registers/access-register.md):

- [ ] GitHub: organisation members, outside collaborators, team membership, deploy keys, Actions secrets
- [ ] Supabase: organisation members; who has production access; API keys in use
- [ ] Netlify: team members; personal access tokens
- [ ] Google Workspace: admin roles; suspended users removed
- [ ] Bitwarden: members and collection access
- [ ] Sentry, Better Stack, Resend, Google Cloud, Meta Business, TrendiPay: members
- [ ] Domain registrar: account access
- [ ] Every leaver since the last review has no access anywhere
- [ ] MFA is on for every account
- [ ] Access register updated; changes linked to Access request issues

Result: list the access removed, and anything that needs a follow-up issue.
