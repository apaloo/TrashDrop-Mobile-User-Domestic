# IT assets and corporate IT support

**Owner:** Application & IT Support Engineer · **Review:** yearly

## Assets

1. Every company laptop and phone is in the [IT asset register](../registers/it-assets.md)
   with a tag, serial, owner and date.
2. Laptops: full-disk encryption on, screen lock ≤ 5 minutes, automatic OS
   updates, company Google account, password manager, no shared logins.
3. Lost or stolen device: report to Support within 1 hour; Support signs the
   person out of Google, GitHub and the password manager and rotates any
   secret that was on the device.
4. Leavers return devices on their last day; devices are wiped before reuse.

## Support desk

| Channel | For |
|---|---|
| `support@` (Google group) | Users of the household and carter apps (via Operations) |
| GitHub **Bug report** / **Production incident** forms | Defects and outages ([incident management](incident-management.md)) |
| GitHub **Access request** form | Joiners, leavers, role changes ([access control](access-control.md)) |
| Direct message to Support | Laptop, email, Wi-Fi and printer problems |

Corporate IT requests (equipment, accounts, Wi-Fi) are answered within 1
business day. Recurring problems are reviewed monthly and fixed at the cause.

## Joiners and leavers

| Joiner (before day 1) | Leaver (by the last day) |
|---|---|
| Access request issue raised by the manager | Access request (Remove) raised by HR |
| Google account, groups, password manager | Suspend Google account; transfer files |
| Laptop from the register, set up and encrypted | Collect laptop and phone; wipe |
| GitHub team, project board | Remove from GitHub, Supabase, Netlify, every vendor in the access register |
| [Onboarding guide](../onboarding.md) issue | Rotate any shared secret the person could see |
